# 145 — Voice EQ matrix (no pitch shift), served at /dev

Task 144's pitch-shift matrix was rejected: the shifted voice sounds
artificial. Perceived age/authority comes largely from spectral balance,
not pitch — so this task tries EQ and dynamics ONLY, with pitch and
duration untouched.

Rules that still apply (documented in the design chat, not in the repo):
- SOCRATES phase length is driven by source.onended, so output duration
  must equal source duration exactly.
- NEVER pitch-shift, never asetrate, never regenerate.
- client/public/voice is READ-ONLY. All audio is generated by Argyrios
  via ElevenLabs; agents only post-process existing files.

## Acceptance criteria — report on each SEPARATELY, under 8 lines total

1. Reuse the SAME 4 source clips as task 144 (same hashes) so the two
   matrices are directly comparable. Report the hashes back.

2. Produce 4 EQ/dynamics variants per clip, no pitch change, spanning
   subtle -> pronounced. Vary low-shelf boost, high-shelf/treble cut,
   presence around 2-4kHz, and gentle compression. At least one variant
   must be EQ-only with no compression, so its effect can be isolated.
   Write to `client/public/voice-matrix-eq/` (gitignored), with the
   unfiltered original copied in alongside each set. Filenames must make
   the parameters legible at a glance. Report the total file count.

3. Report every output's duration next to its source. Any diff over 10ms
   is a FAILURE — report it as such, do not silently drop it. Also
   report peak level per output: if any variant clips (peak >= 0.0 dBFS),
   report it rather than normalising it away silently.

4. Add `/dev/voice-eq`: 4 rows, each with original + 4 labelled variants
   as <audio> elements. No rating controls, listening only. Report the
   element count rendered.

## Constraints
- Sonnet. No screenshots, no Playwright.
- Do NOT call ElevenLabs. Do NOT run voice:generate.
- Do NOT add any post-step to voice:generate yet.
- Every var(--*) must be defined in palette-elaiografia.css.
- Do not modify the task-144 matrix or its route.

## What shipped

- `dev/generate-voice-eq-matrix.ts` (new, throwaway): reuses Task 144's
  exact 4 clips/hashes, applies ffmpeg `bass` (low-shelf), `treble`
  (high-shelf), `equalizer` (peaking, centered 3000Hz, for the 2-4kHz
  "presence" dip) and `acompressor` (gentle downward compression) — no
  `rubberband`, no `asetrate`, nothing that touches playback rate.
  v1 omits `acompressor` entirely (EQ-only). Output goes to the new,
  gitignored `client/public/voice-matrix-eq/`, never
  `client/public/voice` (read-only) or Task 144's `voice-matrix/`
  (untouched — confirmed via `git diff --stat` showing no changes to any
  Task 144 file).
- `dev/verify-voice-eq-matrix.ts` (new): duration check (ffprobe
  `format=duration`, same method as Task 144) plus a peak-level check
  (`ffmpeg -af volumedetect -f null -`, reading `max_volume` from
  stderr via `spawnSync` — `execFileSync` only captures stdout, and
  volumedetect's stats print to stderr).
- `client/src/screens/DevVoiceEqScreen.tsx` (new) + `devRoutes.tsx`:
  `/dev/voice-eq`, same 4-clips-as-rows / 5-labelled-`<audio>` layout as
  `/dev/voice-matrix`, no ratings. `devRoutes.tsx`'s existing 6 entries
  (including Task 144's) are untouched; only a new import + array entry
  appended.
- `.gitignore`: added `client/public/voice-matrix-eq/` (trailing slash —
  real directory, same reasoning as Task 144's entry).
